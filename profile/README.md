## EndpointBench

Device, user and deployment management for **Microsoft Configuration Manager** and **Active Directory** — free, in one window, integrated into the ConfigMgr console.

- **Download:** [latest release](https://github.com/endpointbench/endpointbench/releases/latest) (English and Turkish installers, user guide PDF)
- **Website:** [endpointbench.com](https://endpointbench.com)

Microsoft Configuration Manager ve Active Directory için ücretsiz cihaz, kullanıcı ve dağıtım yönetim aracı. Türkçe ve İngilizce kurulum paketleri [son sürüm](https://github.com/endpointbench/endpointbench/releases/latest) sayfasındadır.
